孕早期运动（1~3个月）

以缓慢为主，打好基础

💡
原则 孕早期胚胎着床未稳，受精卵与母体结合约需2个月，此期运动以"缓慢、低强度"为主。不适合激烈运动，避免腹部震动。
🚶‍♀️

散步 首选运动

孕早期最安全的运动方式。步伐放缓，不要走过快或爬坡太多，保持心跳平稳。每次15~30分钟即可，饭后稍作休息再进行。

🎵

运动胎教 同步胎教

从孕8周开始，可进行运动胎教。孕妈妈轻柔活动身体的同时，通过羊水传递运动感，刺激胎宝宝感官发育。也可结合音乐胎教共同进行。

⚠️
孕早期运动注意 避免剧烈跑跳、仰卧起坐、腹部用力等高强度动作；若有流产迹象（出血、腹痛）应立即停止一切运动并就医。
⚖️
从孕早期开始控制体重 整个孕期体重增加以12～14千克为宜。孕早期通过适当运动配合饮食控制，避免体重过快增加，是整个孕期体重管理的基础。
🏊‍♀️

孕中期运动（4~7个月）

胎儿稳定，运动黄金期

✅
孕5月起可主动参加适度运动 胎宝宝状况已比较稳定，孕妈妈可以主动参加适度运动——控制体重、提高抵抗力、改善妊娠不适、加强骨盆腰部肌肉，使宝宝在分娩时容易娩出。
🏊‍♀️

游泳 最佳全身运动

游泳能锻炼全身，减轻脚腕膝盖负担，缓解腿部水肿和腰部疼痛，放松子宫，锻炼肌肉并强化心肺功能，可提高顺产概率。宝宝在羊水中也会随之变换舒服姿势，变得平静。

  • 下水前用温暖的水淋浴，做基础体操运动，让身体放松
  • 先向两侧做分腿和弯曲动作，同时练习"呼、哈"分娩呼吸法
  • 用自由行走或轻轻跳跃的方法使脉搏渐渐加快
  • 结束后伸展胳膊、肩膀和跟腱，做一套简单体操收尾
🚫
禁止蝶泳 蝶泳会使后背下部严重拱起，拉伤肩膀，孕期严禁进行。
🌿

散步 每日必做

每天坚持散步，有利于全身血液循环，能有效预防静脉曲张。建议每天下午4～5点外出散步，此时阳光适宜，草木释放氧气最强。进入孕中后期，多走动走动更有利于顺产。

👨‍👩‍👧
外出散步时必须有家人陪同，不方便行动时有人扶持，发生意外时可及时处理。
💃

有氧操 改善情绪

做有氧操能一扫烦躁情绪，通过身体活动释放压力，促进血清素分泌。适合孕中期身体条件允许时进行，动作以舒展为主，不要大幅度跳跃。

🤸‍♀️

缓解背部和肩部疼痛的运动 对症运动

孕中期韧带疼痛、背肩不适是常见问题。通过专项拉伸运动、肩颈活动，可有效缓解腰背酸胀，保持身体灵活性。保持平和心态，不要强迫身体完成动作。

🧘‍♀️

孕中期普拉提 — 伸展四肢 书中动作

平躺，配合腹式呼吸，交替互换四肢姿势，锻炼核心肌群，重复5～10次。具体做法：

  • 平躺，左腿伸直，右腿屈膝，右臂向上伸出，左臂自然放在身体左侧
  • 开始腹式呼吸，长长吸入一口气
  • 呼出时，双臂和双腿的姿势分别互换
  • 重复5～10次
🌸

孕妇瑜伽 / 太极拳 降压放松

散步、太极拳、孕妇瑜伽等运动可使全身肌肉放松，对妊娠期高血压的孕妈妈尤其有益，促进血压下降。也有助于缓解孕期紧张情绪，改善睡眠质量。

🧘‍♀️

孕晚期运动（8~9个月）

减轻水肿，锻炼盆底，备战分娩

⚠️
孕晚期运动原则 不走太远的路，站立时间不要过长。进行运动要保证"不疲劳、不剧烈"为前提，一旦出现头晕、气短等不适，应立即停止并就医。
🦵

孕晚期普拉提运动 减轻水肿

孕晚期呼吸不畅、手或脚腕水肿时，推荐做以下普拉提运动：

① 靠墙抬腿
  1. 用垫子垫住头部，臀部尽量贴近墙壁，背部处于舒适状态
  2. 双腿自然伸至墙的上端，保持5分钟
  3. 双腿向两侧分开至感到拉伸效果，再保持5分钟
  4. 注意不要太过吃力
② 抬腿拉伸
  1. 靠墙而坐，两腿向前伸直，右腿下垫两个枕头
  2. 左脚贴地屈膝，慢慢完全伸直右腿
  3. 保持脚趾向上并对脚后跟用力，拉伸后放松
  4. 重复10次后换另一条腿
③ 骨盆转动
  1. 呼气时弯曲双膝，让膝关节放松
  2. 吸气时将髋关节由右向左转动，重心随之自然转换
  3. 进行6～10圈的转动
  4. 用同样方法进行反方向练习
💪

凯格尔运动（盆底肌锻炼）改善漏尿

进行规律的盆底肌锻炼，有利于改善盆底血液循环，减少痔疮不适，预防漏尿。需要长期坚持才能收到良好效果。

  • 全身放松，夹紧臀部和大腿
  • 做深呼吸：吸气时提收肛门
  • 呼气时放松，一提一松为一次
  • 每次做20～30次，每日做3～5次
🤱

缩紧阴道 + 分腿助产运动 临产助力

孕晚期骨盆疼痛、会阴部压迫感时，通过此运动可降低尿失禁发生概率。

● 缩紧阴道
  1. 平躺，吸气，从肛门尽量用力紧缩阴道
  2. 注意不要把力量分散到其他部位
  3. 呼气，慢慢放松。吸气时数到8
  4. 重复5次后改向一侧躺下休息
● 分腿运动
  1. 在平躺的姿势下将膝盖向上举
  2. 用嘴慢慢呼气的同时，按住膝盖并抬起上半身
  3. 动作缓慢，不要用力过猛
🌳

散步 + 瑜伽（缓解腿抽筋）

白天适当多运动：散步、做做瑜伽等，促进血液循环。同时避免站太久或走太多路。伏案工作的职场孕妈妈，每工作1小时适当活动5分钟，双脚可以抬高缓解腿部疲劳。

🏃‍♀️

临产前运动（孕10月）

促进入盆，助力顺产

🎯
孕10月尚未入盆？多运动！ 孕10月胎宝宝还没有入盆的情况并不少见，孕妈妈不要惊慌，在医生建议下多运动，有利于胎宝宝入盆。
推荐动作

🏗️ 爬楼梯

  • 锻炼大腿和臀部肌肉群
  • 帮助胎宝宝入盆
  • 使第一产程尽快到来
  • 可爬单元楼内楼梯
推荐动作

⛰️ 爬小山包

  • 午后14～16点草木释放氧气最强
  • 借爬山进行充氧
  • 感到累要及时休息
  • 下山时注意安全
推荐动作

🚶 散步 + 上下楼梯

  • 过了预产期仍可促进分娩
  • 促进催产素分泌
  • 轻微运动也有利于分娩
  • 不适合整天卧床
分娩技能

🌬️ 腹式呼吸法

  • 脊背挺直靠椅背
  • 双膝和地面成90度
  • 用鼻子吸气至腹部鼓起
  • 呼气比吸气更缓慢且用力
分娩技能

🤲 拉梅兹呼吸法

  • 第一阶段：胸部呼吸法（宫缩5~20分钟一次）
  • 第二阶段：嘶嘶轻浅式呼吸
  • 第三阶段：喘息呼吸法（转移注意力）
  • 第四阶段：哈气运动（防止撕裂）
分娩球操

⚽ 分娩球大步走

  • 吸气弓步，双手举球向上伸展
  • 吐气挺胸，双手放球落于大腿
  • 连续做5次，共做3组
  • 打开骨盆腔空间，减少盆底下坠感
👨
准爸爸注意 孕妈妈外出爬楼梯、爬山、散步时，必须有家人陪同，随时确保安全。如果发生紧急情况，可立即送医。
🚫

运动禁忌 & 停止运动信号

这些情况必须立即停止运动

⛔ 出现以下症状，立即停止运动并就医：
  • 头晕
  • 气短
  • 腹部疼痛
  • 阴道出血
  • 羊水破裂
  • 胸痛
  • 肌肉无力
  • 小腿疼痛 / 肿胀
🏥 需要完全卧床、避免运动的情况：
🩸

前置胎盘出血

必须卧床，禁止任何活动
💉

子痫前期

高血压危重情况需静卧
💧

过早破水

立即平躺，垫高臀部就医
🔒

子宫颈闭锁不全

需要卧床静养
🦋

蝶泳（全程禁止）

拉伤肩膀和后背下部
🏋️

剧烈运动（全程）

造成子宫收缩、流产风险
🦶

脚底按摩

泡脚时禁止，导致腹部不适
🤰

仰卧时间过长

压迫血管，影响血液循环
💡
养胎不必整天卧床 长期卧床会导致孕期抑郁、加重便秘、下肢血液不畅，甚至引发静脉血栓、肌肉萎缩。除非有以上明确禁忌，否则都应进行适量运动。运动要保证母婴健康为前提。
🏙️

特殊场景运动建议

职场、高楼、高血压孕妈妈的专属建议

住高楼

🏢 增加运动量

  • 住高楼的孕妈妈需注意增加日常运动量
  • 电梯与楼梯结合使用
  • 孕晚期可尝试爬楼梯助入盆
职场孕妈

💼 办公间隙运动

  • 每工作1小时活动5分钟
  • 将双脚抬高缓解水肿
  • 坐时两腿避免交叠
  • 不要长时间保持一个姿势
妊娠高血压

❤️‍🩹 降压运动

  • 散步、太极拳、孕妇瑜伽
  • 使全身肌肉放松，促进血压下降
  • 避免激烈活动导致血压波动
预防便秘

🌿 促进肠道蠕动

  • 适当户外运动促进肠道蠕动
  • 养成定时排便的习惯
  • 配合高膳食纤维饮食
